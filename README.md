# TraveloFun - Responsive MERN Stack Project

Welcome to TraveloFun, a responsive web application built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. The project features Firebase authentication for user management, private routes for secure access, and a tour management system for users to explore and manage travel experiences.

## Tools and Technologies Used

- **Frontend**: React.js, Tailwind CSS, React Hook Form
- **Backend**: Express.js, Node.js
- **Database**: MongoDB
- **Authentication**: Firebase Authentication
- **Deployment**: Hosted on Firebase Hosting

## Features

- **User Authentication**: Secure user authentication and authorization using Firebase.
- **Private Routes**: Implementation of private routes to restrict access based on user authentication status.
- **Tour Management**: CRUD operations for managing tours, including creation, editing, and deletion.
- **Responsive Design**: Fully responsive UI ensuring optimal viewing experience across devices.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/your-repo.git
   cd your-repo
2. Install dependencies for both frontend and backend:

   ```bash
   npm install

3. Set up Firebase Authentication and MongoDB:

  - Create a Firebase project and set up Firebase Authentication.
  - Set up MongoDB Atlas or a local MongoDB database.

4. Configure environment variables:
  - Create .env files in both client and server directories with required variables.
5. Run the application:
    ```bash
   npm run dev
